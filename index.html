Deploy to Home Assistant
HA Floorplan Studio can automatically create and manage a dedicated SSH key for this computer.
SSH Setup
One manual step may be required in Home Assistant
1. Open Home Assistant.
2. Go to Settings → Add-ons.
3. Open the SSH / Terminal add-on you use.
4. Open its Configuration page.
5. Find authorized_keys, Public Keys, or the SSH key configuration section.
6. Paste the public key shown above.
7. Save the add-on configuration.
8. Restart the SSH add-on.
9. Return here and click Test Connection.
SSH add-ons can use slightly different configuration names. If you do not see authorized_keys, check the documentation for your installed SSH add-on.
